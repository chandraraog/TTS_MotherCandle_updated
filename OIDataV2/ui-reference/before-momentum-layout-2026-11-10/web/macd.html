Report source / scanner rules

Stock list chooses what to scan. Enter a scan price cutoff (0 disables it). Stocks at or below it are skipped after the first candle fetch. All MACD timeframes use Fyers candles; Bhavcopy F&O uses the latest saved NSE report.

Alerts: two aligned timeframes become three or more in the same direction across M, W, D, 1H. First observation sets the baseline. One alert attempt per stock per IST day.

Reads macd_scan_report.html generated by macd_mtf_scanner.py. Checks for file updates every 5 seconds. Opening or refreshing this page and restarting the server do not launch a scan. Only Run scan or an enabled 60-minute schedule starts one. Run scan starts another background scan; duplicate clicks do not start parallel jobs. Reload report only rereads the saved result.

Scanner and new reports are in OIDataV2. Scans share the dashboard request budget and can take several minutes. The last completed report remains visible during a scan. Demo mode does not make broker calls.
